# COCO-pretrained Mask R-CNN: 20-band-combination RTS ablation

This is a clean, reusable project for the first spatial-method experiment: **full-image Mask R-CNN with full COCO instance-segmentation pretraining** across 20 selected three-band combinations.

The notebook is only the Kaggle runner. Model, data loading, metrics, training and plotting live in importable Python files under `src/` so the same code can be opened in VS Code and committed to GitHub.

## 1. Experimental protocol

- Dataset: 2026 GeoAI Arctic Challenge `competition_release`.
- Labelled images: 756.
- Existing grouped split: generated by grouping pixel-overlapping chips; do not regenerate or change it for this comparison. The loader independently audits the saved connected-component groups, checks that every labelled image ID appears exactly once, and raises an error if any pixel-overlap group crosses train, validation or local-test partitions.
- Fold used for the initial band screen: fold index `1` (the second fold, zero-based).
- Expected fold counts: 523 train, 112 validation, 121 fixed local-test images.
- Seed: 42.
- Model: `torchvision.models.detection.maskrcnn_resnet50_fpn` with `MaskRCNN_ResNet50_FPN_Weights.COCO_V1`.
- The complete COCO checkpoint is loaded. The class-specific box classifier/regressor and the final mask-logit convolution are replaced for two classes (background and RTS); the pretrained mask upsampling layer, ROI feature towers, FPN, RPN and remaining ROI heads are retained.
- `trainable_backbone_layers=3` freezes the ResNet stem and first residual stage while allowing later stages to fine-tune.
- Each selected channel is stretched with train-split-only 2nd/98th percentiles to `[0, 1]`. The three channels are passed to the model in the exact order listed in each combination (non-RGB combinations are pseudo-RGB inputs). Torchvision then applies the standard input normalization expected by the COCO-pretrained weights.
- All 20 combinations use the same split, seed, optimizer, image resizing, anchor configuration, maximum detections and evaluation implementation.
- The local test set is not used to rank combinations. The first sweep ranks validation results only.

The combinations are a curated experimental set, not the exhaustive set of all possible 3-band combinations.

## 3. Open the project in VS Code

1. Download and extract `coco_maskrcnn_band_ablation.zip`.
2. Open VS Code.
3. Select **File → Open Folder** and choose the extracted `coco_maskrcnn_band_ablation` folder.
4. The main files are:
   - `src/data.py` — NPZ reading, saved grouped split, band scaling, masks and data loaders.
   - `src/model.py` — full COCO Mask R-CNN initialization and RTS head replacement.
   - `src/metrics.py` — challenge-official segmentation AP, AP50, AP75, size-specific AP and mean IoU.
   - `src/experiment.py` — training, checkpointing, early stopping and resume support.
   - `src/plot_results.py` — ranked metric charts and dashboard.
   - `src/visualize.py` — ground-truth/prediction mask overlays.
   - `configs/band_combinations.json` — the 20 experimental combinations.
   - `notebooks/kaggle_coco_20_band_ablation.ipynb` — Kaggle execution notebook.
5. For local VS Code development, create a Python environment and install the required PyTorch/Torchvision pair for your machine, then install `requirements-kaggle.txt`. Full training is intended for Kaggle GPU; do not expect the 20-run sweep to be practical on CPU.

You do not need to create these files one by one: they are already included in this extracted project folder.

## 4. Run on Kaggle

### Attach three datasets

1. The GeoAI Arctic Challenge competition data dataset.
2. The existing `rts-mask-r-cnn-band-scale-code` dataset, because it contains the trusted `Experiments/splits/grouped_folds.json` file already used in the previous experiment.
3. This project folder uploaded as a Kaggle Dataset. A suggested dataset slug is `coco-maskrcnn-band-ablation-code`.

The notebook searches `/kaggle/input` for the project config, competition `metadata/band_names.json`, and `grouped_folds.json`. It can also extract the project ZIP into `/kaggle/working` if Kaggle exposes it as a ZIP instead of unpacking it. If more than one split JSON is attached, it prefers the existing `rts-mask-r-cnn-band-scale-code` path.

### Kaggle settings

- Accelerator: GPU (T4 or better).
- Internet: enabled for the first download of the COCO_V1 checkpoint.
- Do not `pip install --upgrade torch torchvision`; use Kaggle's preinstalled matched PyTorch/Torchvision versions.

Open `notebooks/kaggle_coco_20_band_ablation.ipynb` in Kaggle and run cells from top to bottom.

```text
│   └── ... C20/
└── figures/
    ├── metrics_dashboard.png
    ├── ranked_AP.png
    ├── ranked_AP50.png
    ├── ranked_AP75.png
    ├── ranked_mIoU.png
    ├── ranked_AP_by_size.png
    └── ranked_results_by_AP.csv
```

`AP`, `AP50`, `AP75` and size-specific AP use the competition's own `tools/evaluate_coco.py` settings (including its maximum detections and area ranges). `mIoU` is the mean image-level IoU between the union of predicted masks with score ≥ 0.5 and the union of ground-truth masks.

The bar charts rank each metric independently; the highest score is at the top and extends furthest right. Scores in the result CSV are stored as fractions (e.g. `0.12`); charts and notebook display them as percentages.

The downloadable result archive excludes `.pth` model checkpoints to keep its size reasonable. Checkpoints remain in the Kaggle output folder and should be preserved as notebook outputs.

## 6. Important interpretation

This is the **first single-fold band-combination screen**, not the final statistical claim. Once the best combinations are identified on validation, evaluate the strongest candidates across all grouped folds and report mean ± standard deviation. Use the fixed local-test set only for final, limited assessment; do not tune all 20 combinations using local-test results.

This notebook implements the full-image Mask R-CNN spatial method. The patch-Mask-R-CNN and 3×3-centre-pixel methods can be added as separate, controlled experiment families later.
